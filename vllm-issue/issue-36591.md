#### 技術細節

```python
# GSM8K benchmark 設定範例
from vllm import LLM, SamplingParams

# 1. 載入模型
llm = LLM(model="your-model")

# 2. 設定 sampling 參數
sampling_params = SamplingParams(
    temperature=0.0,
    max_tokens=1024
)

# 3. 準備 GSM8K 測試數據
with open("gsm8k_test_prompts.txt") as f:
    prompts = f.readlines()

# 4. 執行 benchmark
results = llm.generate(prompts, sampling_params)

# 5. 計算 accuracy
accuracy = calculate_accuracy(results, gsm8k_answers)
```
