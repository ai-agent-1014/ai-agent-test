# [Bug]: DPEngineCoreProc may re-arm DP wave while paused

- **Issue**: #36594
- **Author**: @junjzhang

## 🔍 深入分析

### 📋 問題背景

vLLM 的 **DP Engine Core Process (DPEngineCoreProc)** 在處理 **DP wave (Data Parallel wave)** 時存在狀態管理問題：
- **錯誤行為**：DP wave 被錯誤地 re-arm（重新啟動）即使處於 paused 狀態
- **影響**：可能導致並發問題、計算重複或資源浪費

### 🎯 問題分析

#### 問題場景
```python
# 問題流程
1. DP wave 啟動 → running
2. 系統進入 paused 狀態 → paused
3. DPEngineCoreProc 錯誤地 re-arm DP wave → running (❌ 錯誤)
4. 結果：DP wave 重複執行或狀態混亂
```

#### 技術根源

| 問題點 | 說明 |
|--------|------|
| **狀態機錯誤** | paused 狀態未正確阻止 re-arm |
| **訊號處理** | 錯誤的訊號觸發 re-arm |
| **並發控制** | 缺少狀態檢查 |

### 🛠️ 修復機制

#### 狀態機修復
```python
# 修復：正確處理 paused 狀態
class DPEngineCoreProc:
    def __init__(self):
        self.state = "idle"  # idle | running | paused
        self.lock = threading.Lock()
    
    def re_arm_dp_wave(self):
        with self.lock:
            # 修復：檢查當前狀態
            if self.state == "paused":
                return  # 不允許 re-arm
            
            # 只在 running 或 idle 狀態下 re-arm
            self._execute_dp_wave()
            self.state = "running"
```

#### 關鍵修復點

```python
# 1. 狀態檢查
def can_re_arm_dp_wave(self):
    return self.state in ["idle", "running"]

# 2. 狀態轉換檢查
def pause_dp_wave(self):
    if self.state == "running":
        self.state = "paused"
        return True
    return False

# 3. 保護性檢查
def re_arm_dp_wave(self):
    if not self.can_re_arm_dp_wave():
        logger.warning("Cannot re-arm DP wave while paused")
        return
    # 執行 re-arm 邏輯
```
